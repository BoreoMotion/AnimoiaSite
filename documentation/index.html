Animoia documentation¶

Animoia is a motion-design and compositing workspace for building animated compositions from video, images, text, vector shapes, audio, and generated graphics. These guides focus on what you can create, how controls change the result, and how the editor’s tools work together.

Start here¶

Animoia user guide

Learn the workspace, create compositions and layers, edit in the viewer and timeline, work with masks and motion tracking, and export finished work.

Properties and animation

Shape layer appearance and motion with properties, keyframes, easing, expressions, and animation modifiers.

Effects reference

Browse effects by category and learn what every control changes visually or audibly.

Keyboard shortcuts

Find keyboard shortcuts for tools, playback, timeline editing, and common commands.

Suggested paths¶

Creating your first animation¶

  1. Follow Project and file workflow to make a composition and bring in media.

  2. Learn Timeline to arrange layers in time.

  3. Use Keyframes and easing to add keyframes and shape the motion.

  4. Explore Effects reference to develop the final look.

  5. Finish by exporting your composition.

Tip

Once you know your way around, the FX Console reaches any effect, preset, or command by name from the keyboard, which is usually faster than browsing the panels.

Working with vector artwork¶

Read Shape, then continue to Pen and Mask tool and Paths for path-based operations.

Animating text¶

Start with Text, then see Text for character- and range-based text animation.

Working with sound¶

See Audio for layer audio controls and Audio for audio effects and sound-driven visuals.

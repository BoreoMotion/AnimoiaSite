Animoia documentation
=====================

Animoia is a motion-design and compositing workspace for building animated compositions from video, images, text, vector shapes, audio, and generated graphics. These guides focus on what you can create, how controls change the result, and how the editor’s tools work together.

Start here
----------

:doc:`guide`
   Learn the workspace, create compositions and layers, edit in the viewer and timeline, work with masks and motion tracking, and export finished work.

:doc:`properties-and-animation`
   Shape layer appearance and motion with properties, keyframes, easing, expressions, and animation modifiers.

:doc:`effects-reference`
   Browse effects by category and learn what every control changes visually or audibly.

:doc:`shortcuts`
   Find keyboard shortcuts for tools, playback, timeline editing, and common commands.

Suggested paths
---------------

Creating your first animation
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

#. Follow :ref:`creating-a-project` to make a composition and bring in media.
#. Learn :ref:`layers-and-timeline` to arrange layers in time.
#. Use :ref:`animating-properties` to add keyframes and shape the motion.
#. Explore :ref:`effects-reference` to develop the final look.
#. Finish by :ref:`exporting your composition <rendering-and-export>`.

.. tip::

   Once you know your way around, the :ref:`FX Console <fx-console>` reaches any effect, preset, or command by name from the keyboard, which is usually faster than browsing the panels.

Working with vector artwork
~~~~~~~~~~~~~~~~~~~~~~~~~~~

Read :ref:`shape-layers`, then continue to :ref:`masks-and-paths` and :ref:`effects-paths` for path-based operations.

Animating text
~~~~~~~~~~~~~~

Start with :ref:`text-layers`, then see :ref:`effects-text` for character- and range-based text animation.

Working with sound
~~~~~~~~~~~~~~~~~~

See :ref:`audio-workflows` for layer audio controls and :ref:`effects-audio` for audio effects and sound-driven visuals.

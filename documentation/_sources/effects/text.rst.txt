.. _effects-text:

Text
====

Animates the characters of a text layer. Every effect below is listed in the sidebar, so you can jump straight to one. Return to :doc:`../effects-reference` for stack behavior shared by all effects.

.. _effect-text-typewriter:

Typewriter
----------

Animates text with typewriter behavior while keeping the characters editable. Add it from **Effects > Text** by double-clicking it or dragging it onto a compatible layer.

.. note::

   Apply this only to a text layer.

.. list-table:: Properties
   :header-rows: 1
   :widths: 24 18 58
   :class: effect-properties

   * - Name
     - Control
     - Visual or audible result
   * - Progress
     - Number
     - Drives the typewriter from its starting state to its finished state; keyframe it to animate the change over time.
   * - Cursor
     - Menu
     - Chooses the cursor drawn at the typing position, or turns it off.
   * - Blink Rate
     - Number
     - Sets how quickly typewriter evolves or repeats over time.

.. _effect-text-transform-letter:

Transform by Letter
-------------------

Animates text with transform by letter behavior while keeping the characters editable. Add it from **Effects > Text** by double-clicking it or dragging it onto a compatible layer.

.. note::

   Apply this only to a text layer.

.. list-table:: Properties
   :header-rows: 1
   :widths: 24 18 58
   :class: effect-properties

   * - Name
     - Control
     - Visual or audible result
   * - Progress
     - Number
     - Drives the transform by letter from its starting state to its finished state; keyframe it to animate the change over time.
   * - Transition Softness
     - Number
     - Overlaps neighboring letters’ timing so the animation flows through the word instead of stepping letter by letter.
   * - Order
     - Menu
     - Chooses the sequence the letters animate in.
   * - Random Seed
     - Number
     - Changes the irregular variation in the transform by letter, from calm and even to visibly scattered.
   * - Position
     - 2D control
     - Moves the effect’s focal point or generated element across the layer.
   * - Uniform Scale
     - Toggle
     - Turns uniform scale on or off.
   * - Scale
     - 2D control
     - Makes the pattern or distortion features larger or smaller.
   * - Rotation
     - Number
     - Rotates the result around its center.
   * - Opacity
     - Number
     - Changes how strongly the effect is visible without changing its shape.
   * - Blur
     - Number
     - Softens the result, blending each pixel with its neighbors so detail and edges fade out.
   * - Easing
     - Menu
     - Chooses the acceleration curve each letter follows as it animates.
   * - Easing Intensity
     - Number
     - Sets how pronounced that easing curve is, from nearly linear to sharply accelerated.

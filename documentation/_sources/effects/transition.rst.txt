.. _effects-transition:

Transition
==========

Reveals or removes a layer over time. Every effect below is listed in the sidebar, so you can jump straight to one. Return to :doc:`../effects-reference` for stack behavior shared by all effects.

.. _effect-corruption:

Corruption
----------

Reveals or removes the layer through an animated corruption pattern. Add it from **Effects > Transition** by double-clicking it or dragging it onto a compatible layer.

.. list-table:: Properties
   :header-rows: 1
   :widths: 24 18 58
   :class: effect-properties

   * - Name
     - Control
     - Visual or audible result
   * - Progress
     - Number
     - Drives the wipe from start to finish: at the low end the layer is still fully visible, and at the high end it has been completely wiped away. Keyframe this to play the transition.
   * - Block Width
     - Number
     - Sets the horizontal size of the block.
   * - Block Height
     - Number
     - Sets the vertical size of the block.
   * - Feather
     - Number
     - Softens the edge by blending it gradually into the surrounding image.

.. _effect-card-shuffle:

Card Shuffle
------------

Reveals or removes the layer through an animated card shuffle pattern. Add it from **Effects > Transition** by double-clicking it or dragging it onto a compatible layer.

.. list-table:: Properties
   :header-rows: 1
   :widths: 24 18 58
   :class: effect-properties

   * - Name
     - Control
     - Visual or audible result
   * - Progress
     - Number
     - Drives the wipe from start to finish: at the low end the layer is still fully visible, and at the high end it has been completely wiped away. Keyframe this to play the transition.
   * - Columns
     - Number
     - Divides the frame into more or fewer columns, so each cell of the card shuffle gets smaller and more numerous.
   * - Rows
     - Number
     - Divides the frame into more or fewer rows, so each cell of the card shuffle gets smaller and more numerous.
   * - Flip Axis
     - Menu
     - Chooses the axis each card turns on as it flips.
   * - Randomness
     - Number
     - Changes the irregular variation in the card shuffle, from calm and even to visibly scattered.

.. _effect-clock-wipe:

Clock Wipe
----------

Reveals or removes the layer through an animated clock wipe pattern. Add it from **Effects > Transition** by double-clicking it or dragging it onto a compatible layer.

.. list-table:: Properties
   :header-rows: 1
   :widths: 24 18 58
   :class: effect-properties

   * - Name
     - Control
     - Visual or audible result
   * - Progress
     - Number
     - Drives the wipe from start to finish: at the low end the layer is still fully visible, and at the high end it has been completely wiped away. Keyframe this to play the transition.
   * - Start Angle
     - Number
     - Rotates where the sweep begins around the circle.
   * - Blades
     - Number
     - Splits the circle into this many equal wedges, each sweeping its own clock hand at the same time, so the wipe closes like blinds bent around the center.
   * - Wipe Center
     - 2D control
     - Moves the wipe center in the viewer, changing where clock wipe is centered or begins.
   * - Wipe
     - Menu
     - Chooses which way the hand travels: clockwise, counterclockwise, or opening out from both sides at once.
   * - Feather
     - Number
     - Softens each wedge edge as a fraction of one wedge, blurring the sweeping boundary.
